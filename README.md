# PatVerb

Free, open-source reverb (VST3 + standalone) with a particle-galaxy visual that reacts to your
audio: every hit bursts into light, particles live as long as the reverb tail, size opens the
galaxy, and you can drag it to change size and decay.

Seven algorithms (Hall, Room, Chamber, Plate, Spring, Shimmer, Cloud), tempo-synced pre-delay,
early/late balance, damping and bass cut, modulation, width, ducking, freeze, wet filters and
26 presets.

Build: `powershell -ExecutionPolicy Bypass -File tools/build.ps1 -Test`. AGPL-3.0, built with JUCE.
